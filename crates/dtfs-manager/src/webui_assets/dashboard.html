Migrate data to another tier / datacenter

Adds a replica satisfying the chosen tier (and, when set, datacenter) for every chunk whose file path begins with the prefix. Existing replicas are left in place; this is additive and never deletes data.

Flush cache replicas

Drops every cache-class replica (warm/hot, depending on the volume policy) for files under the path prefix and sets a per-chunk cooldown to prevent immediate re-promotion. Mandatory replicas (the durable anchor) are preserved; any chunk whose flush would strand the anchor is refused and audited.

Decommission

Permanently removes the node from the cluster registry. The manager refuses while the node still holds any chunk replica: drain it (maintenance + re-replication) first. Both fields below land in the audit log.

Remove dead node

For a node that is Down/Failed and will not come back. Preview first: the manager computes which replica rows can be dropped safely and which chunks have no other live copy (data loss). Leader only. operator_id and reason land in the audit log.
